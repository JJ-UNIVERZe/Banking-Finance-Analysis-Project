# 🏦 Banking Customer Transaction & Financial Performance Analysis

## 🎯 Project Aim

To analyze banking customer transactions, account activity, loan performance, and financial trends using Microsoft Excel in order to:

- Understand customer behavior across account types, transaction types, and channels.
- Identify transaction patterns across months and branches.
- Evaluate loan approvals, rejections, delayed payments, and outstanding balances.
- Highlight opportunities to improve customer engagement, transaction reliability, and financial performance.

## 📊 Key Metrics

| Metric | Value |
|---|---:|
| Total Customers | 1,200 |
| Total Transactions | 1,200 |
| Total Transaction Amount | ₹5,702.01K |
| Total Loan Amount | ₹60,934.57K |
| Loan Approval Rate | 78.59% |
| Delayed Payment Rate | 10.85% |

> **Note:** The dataset contains 1,200 customer records and 1,200 transaction records, with one transaction record per customer.

## 🛠️ Tools Used

- **Microsoft Excel**
- Data cleaning and standardization
- Excel formulas: `COUNTIF`, `COUNTIFS`, `SUMIFS`, `TRIM`, `CLEAN`, `PROPER`, and `TEXT`
- PivotTables and PivotCharts
- KPI cards and dashboard layout

## 🔎 What the Dashboard Answers

- How many customers and transactions are represented, and what is the total transaction value?
- How does transaction value change month by month?
- Which account type is most common?
- Which transaction types contribute the most transaction value?
- Which transaction channels are used across the dataset?
- Which loan types have the highest total loan amounts?
- What proportion of loan applications are approved versus rejected?
- How do branches compare by transaction value, loan amount, and transaction volume?
- What are the loan approval rate and delayed payment rate?

## 📈 Highlights & Key Insights

- **Savings accounts are the largest account type:** 580 of 1,200 records (approximately **48.3%**).
- **Loan approval rate:** **78.59%**, based on 617 approved and 168 rejected applications.
- **Delayed payment rate:** **10.85%**, based on 67 delayed payments among 617 approved loans.
- **Deposits lead transaction value:** approximately ₹2.21 million, around 39% of total transaction value.
- **Monthly transaction value peaks in May:** approximately ₹603K; September is the lowest month at approximately ₹372K.
- **Personal loans have the highest total loan amount:** approximately ₹16.8 million, closely followed by auto loans at approximately ₹16.3 million.
- **Chennai leads in transaction value:** ₹900.5K.
- **Coimbatore has the highest total loan amount by branch:** approximately ₹8.50 million.
- Pending and failed transactions are areas identified for further investigation.
